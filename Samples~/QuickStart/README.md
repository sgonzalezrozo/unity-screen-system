# Quick Start sample

1. Run **Tools > Screen System > Setup**.
2. Select a folder, then use **Assets > Screen System > New Screen Feature** to create a screen called `ShopMain`.
3. Run **Tools > Screen System > Rebuild Registry Cache**.
4. Add `SampleScreen` to the `ShopMain` prefab.
5. Add `SampleBoot` to a GameObject in your first scene.
6. Press Play. The Console shows `Shown: ShopMain`.
